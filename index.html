לשליחת מיילים (Resend):
1. הירשם ב-resend.com (חינם עד 3,000 מיילים בחודש)
2. צור API key
3. הוסף אותו ל-Supabase Secrets בשם RESEND_API_KEY

לחיבור Zoho CRM:
1. היכנס ל-api-console.zoho.com
2. צור Self Client / Server-based Application
3. הוסף ל-Supabase Secrets:
  ZOHO_CLIENT_ID
  ZOHO_CLIENT_SECRET
  ZOHO_REFRESH_TOKEN
  ZOHO_DATA_CENTER (com/eu/in)

ל-AI (Anthropic):
1. צור key ב-console.anthropic.com
2. הוסף ל-Supabase Secrets בשם ANTHROPIC_API_KEY
